## How to Run

Requires Python 3.8 or newer.

```bash
git clone https://github.com/ParthAg0703/IC-2K24-65-PythonLab-ParthAgrawal.git
cd IC-2K24-65-PythonLab-ParthAgrawal
python "Python Lab 5/atm.py"
```

Most programs read input from the keyboard, so run them in a terminal. Labs 6 and 7 also include `.md` files with written answers, which are meant to be read rather than run.

- Lab 1: data types, type conversion, operators, string methods and slicing
- Labs 2–4: `for` loops, nested loops, lists and 2D lists
- Lab 5: `while` loops, conditionals, functions, `random`, binary search idea
- Lab 6: Big-O time and space complexity, recursion cost
- Lab 7: dictionaries, nested dictionaries, comprehensions, `get`, `setdefault`, shallow vs deep copy
