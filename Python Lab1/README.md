# Python Lab 1 – Python Basics

Introductory exercises on variables, data types, user input, operators, strings and escape sequences.

## Files

| File | Description |
|---|---|
| `variable_practice.py` | Declares `str`, `int`, `float` and `bool` variables and prints each value with its type |
| `greeting.py` | Takes name, age and city as input and prints a greeting using an f-string |
| `arithmetic.py` | Takes two numbers and prints sum, difference, product, quotient and remainder |
| `celcius_to_fahrenheit_conversion.py` | Converts Celsius to Fahrenheit using `F = C × 9/5 + 32` |
| `string_manipulation.py` | Prints a name in uppercase, lowercase, reversed (`[::-1]`) and its length |
| `escape_sequence.py` | Prints a tab-aligned price list using `\t` and `\n` |
| `Section_B.py` | The six "predict the output" expressions from Section B, as runnable code |
| `Section A.txt` | Section A: fill-in-the-blank concept answers (`input()`, `type()`, `**`, `//`, `%`, comments, naming rules) |
| `Section B.txt` | Section B: predicted outputs for the six expressions |
| `Section B Output.png` | Screenshot of the actual output, to check the predictions |

## Run

```bash
python greeting.py
python arithmetic.py
```

## Concepts

`input()` always returns a string. `int()` and `float()` convert it. `**` is exponentiation, `//` is floor division and `%` gives the remainder.
