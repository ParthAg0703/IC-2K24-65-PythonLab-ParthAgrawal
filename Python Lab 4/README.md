# Python Lab 4 – Nested Loops and 2D Lists

## Files

| File | Description |
|---|---|
| `star_pattern.py` | Reads `n` and prints a right-angled star triangle with `n` rows |
| `matrix_operation.py` | Reads a 3×3 matrix and performs several operations on it |

### `matrix_operation.py`

After entering nine integers, the program prints:

1. The matrix
2. Sum of all elements
3. Sum of the main diagonal
4. Largest element
5. Smallest element
6. Transpose

All of it is done with explicit nested loops and no libraries.

## Run

```bash
python star_pattern.py
python matrix_operation.py
```

Sample input for the matrix program: `1 2 3 4 5 6 7 8 9` (one value per prompt). The sum is 45, the diagonal sum is 15 and the transpose swaps rows and columns.
